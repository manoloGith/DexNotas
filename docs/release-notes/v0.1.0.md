Primera versión de DexNotas, un editor de texto y código para Samsung DeX.

- Pestañas que vuelven con su texto sin guardar al reabrir la app.
- Editor propio sin límite de tamaño: archivos de decenas de MB con colores y JSON de una sola
  línea enormes.
- Buscar y reemplazar con expresiones regulares y grupos; buscar en todas las pestañas.
- Resaltado de 25 lenguajes; números de línea.
- Vista previa de Markdown y HTML en doble panel redimensionable (Ctrl+Mayús+V), con el motor web
  del sistema: CSS, JavaScript, imágenes y enlaces.
- Formatear, compactar y validar JSON y XML; validar YAML y TOML.
- UTF-8, UTF-16 y ANSI, con o sin BOM; CRLF, LF y CR.
- Macros con nombre y atajo.

Versión de prueba: lo que conviene comprobar está en docs/testing.md.
