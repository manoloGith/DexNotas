DexNotas 0.2.0: casi 200 lenguajes con colores.

- Resaltado de unos 195 lenguajes: los 25 de antes con tree-sitter y 169 más con highlight.js
  (Kotlin, Dart, Haskell, Elixir, Scala, R, Perl, Fortran, VHDL, Dockerfile, Makefile, Nginx,
  LaTeX, Diff, GraphQL, ensamblador…), detectados por la extensión, el nombre del archivo o el `#!`.
- Menú Lenguaje por iniciales (A, B, C…), con el rango de cada letra a la vista.
- Los bloques de código de Markdown se colorean también con esos lenguajes.
- DexFiles: DexNotas se declara para unas 350 extensiones y aparece siempre en «Abrir con».
- Icono azul claro; las flechas de «Ordenar líneas» ya se ven bien.

Incluye todo lo de 0.1.0: editor sin límite de tamaño, pestañas que vuelven con su texto, buscar y
reemplazar con regex, vista previa de Markdown y HTML con el motor web, formato JSON/XML, UTF-8,
UTF-16 y ANSI, macros.

Versión de prueba: lo que conviene comprobar está en docs/testing.md.
